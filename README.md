# NextWealth — AI Data Labeling & Annotation Solutions

An aesthetic, Apple-minimalistic web application for **NextWealth**, showcasing high-precision Human-in-the-Loop (HITL) data labeling and annotation solutions trusted by Fortune 500 AI teams.

> **"Your AI is only as good as the data behind it."**  
> Fortune 500 AI teams trust NextWealth’s 5,000+ specialists—trained, managed, and operating from Tier-2 India to label the data that models cannot get right on their own.

---

## ✨ Features

- **Apple Minimalist Aesthetic**: Clean typography inspired by SF Pro / Inter, frosted glassmorphism (`backdrop-filter: blur(24px)`), refined dark titanium and ceramic light themes.
- **Interactive HITL Annotation Studio**:
  - Live workbench simulating annotation inspection across 4 mission-critical verticals: *Automotive & LiDAR*, *Healthcare & Diagnostics*, *Retail & eCommerce*, and *BFSI Fraud Analytics*.
  - Mode toggle: Compare **Raw Model Predictions** against **NextWealth HITL Ground Truth** with dynamic visual bounding overlays.
  - Interactive confidence threshold slider and live accuracy telemetry.
- **Dynamic Metric Counters**: Animated ticker showing *5,000+ Specialists*, *NPS 85+*, *99.8% Precision SLA*, and *6 Core Industry Verticals*.
- **Agile Pipeline Architecture**: 4-step workflow covering ingestion, specialist labeling, 3-tier consensus QA, and continuous model active learning.
- **Industry Solutions Grid**: Dedicated bento-grid cards for BFSI, Healthcare/Lifesciences, Media & Technology, Retail & eCommerce, Automotive ADAS, and Industrial/Manufacturing.
- **Social Impact Spotlight**: Highlighting the Tier-2 India impact model with 5,000+ careers created and 55%+ women workforce representation.
- **Interactive Proof-of-Concept Modal**: Apple-style `<dialog>` modal with validation and submission confirmation.
- **Global Presence**: Interactive contact cards for Bengaluru Innovation HQ (India) and Frisco Corporate Office (USA) with one-click copy and toast notifications.

---

## 🛠️ Tech Stack

- **Frontend**: Semantic HTML5, Vanilla CSS3 (Custom properties, CSS Grid/Flexbox, glassmorphism), Vanilla JavaScript (ES6+).
- **Typography**: Apple system font stack (`SF Pro Display`, `Inter`, `Outfit`).
- **Server**: Lightweight zero-dependency Node.js HTTP server.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/iamsameer376/nextwealth.git
cd nextwealth
```

### 2. Run Locally
You can run the built-in lightweight static server:
```bash
node server.js
```
Then open [http://127.0.0.1:3000/](http://127.0.0.1:3000/) in your browser.

Alternatively, you can open `index.html` directly in any web browser.
